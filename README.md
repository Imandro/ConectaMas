### Características destacadas

- **📖 Biblia completa offline** — los 66 libros en español (RVR1960) disponibles sin internet
- **🎮 5 juegos bíblicos interactivos** — Ordena el Versículo, Pregunta Relámpago, Empareja Libros, Completa el Verso, Clasifica el Libro
- **💬 Comunidad** — Foro donde compartir oraciones, testimonios y consejería
- **📅 Devocionales diarios** — Con imágenes de alta calidad (Unsplash) y reflexiones profundas
- **❤️ SOS / Emergencia** — Acceso rápido a promesas bíblicas y oraciones en momentos difíciles
- **🦙 Llami, tu mascota virtual** — Un compañero que crece contigo en tu caminar espiritual
- **📊 Seguimiento de progreso** — Estadísticas diarias, rachas, experiencia y logros
- **🔔 Notificaciones push** — Recordatorios y versículos del día
- **📱 PWA + APK** — Funciona como app instalada en Android, iOS y escritorio
- **🌐 Offline-first** — La Biblia y los juegos funcionan sin conexión

## 🚀 Inicio Rápido

```bash
# Clonar el repositorio
git clone https://github.com/Imandro/ConectaMas.git
cd ConectaMas

# Instalar dependencias
npm install

# Configurar variables de entorno
cp .env.example .env.local
# Editar .env.local con tus credenciales (DB, NextAuth, etc.)

# Iniciar en modo desarrollo
npm run dev
```

### Prerrequisitos

- Node.js 18+
- PostgreSQL (o Neon serverless)
- Una cuenta en Vercel (para deploy)
